# Dossier import/

Dépose ici ta matière **en vrac**, sans rien trier : textes, photos, PDFs, liens, brouillons...

À l'étape 1 (voir `../documentation/01_preparer_contenu.md`), l'IA lit tout ce qu'il y a dans ce dossier et te propose une structure rangée dans `contenu/`.

Ce dossier est privé : il n'est pas envoyé sur GitHub (voir `.gitignore`).
