# Dossier 1_import/

Dépose ici ta matière **en vrac**, sans rien trier : textes, photos, PDFs, liens, brouillons...

À l'étape 1 (voir `../0_documentation/01_import.md`), tu remplis ce dossier. À l'étape 2 (`../0_documentation/02_contenu.md`), l'IA lit tout ce qu'il contient et te propose une structure rangée dans `2_contenu/`.

Ce dossier est privé : il n'est pas envoyé sur GitHub (voir `.gitignore`).
