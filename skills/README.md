# Skills IA — prompts prêts à coller

Chaque étape de l'atelier a un prompt IA prêt à coller dans OpenCode. Les prompts sont dans les fichiers de `../0_documentation/`, à la section **« La commande (à donner à l'IA) »**.

| Étape | Fichier | Section |
|---|---|---|
| 1. Remplir le vrac | `../0_documentation/01_import.md` | méthode manuelle, pas de prompt |
| 2. Préparer le contenu | `../0_documentation/02_contenu.md` | « La commande (à donner à l'IA) » |
| 3. Inspiration | `../0_documentation/03_inspiration.md` | « La commande (à donner à l'IA) » |
| 4. Production | `../0_documentation/04_production.md` | « La commande (à donner à l'IA) » |
| 5. Déploiement | `../0_documentation/05_deploiement.md` | « La commande (à donner à l'IA) » |
| 6. Autonomie | `../0_documentation/06_autonomie.md` | « Méthode avec IA » (par test) |

## Usage

1. Ouvrir le fichier de l'étape dans `0_documentation/`
2. Copier le bloc de code de la section « La commande (à donner à l'IA) »
3. Le coller dans OpenCode
4. Répondre aux questions que l'IA pose (validation par bloc)
