# Skills IA — prompts prêts à coller

Chaque étape de l'atelier a un prompt IA prêt à coller dans OpenCode. Les prompts sont dans les fichiers de `../documentation/`, à la section **« La commande (à donner à l'IA) »**.

| Étape | Fichier | Section |
|---|---|---|
| 1. Préparer le contenu | `../documentation/01_preparer_contenu.md` | « La commande (à donner à l'IA) » |
| 2. Inspiration | `../documentation/02_inspiration.md` | « La commande (à donner à l'IA) » |
| 3. Production | `../documentation/03_production.md` | « La commande (à donner à l'IA) » |
| 4. Déploiement | `../documentation/04_deploiement.md` | « La commande (à donner à l'IA) » |
| 5. Autonomie | `../documentation/05_autonomie.md` | « Méthode avec IA » (par test) |

## Usage

1. Ouvrir le fichier de l'étape dans `documentation/`
2. Copier le bloc de code de la section « La commande (à donner à l'IA) »
3. Le coller dans OpenCode
4. Répondre aux questions que l'IA pose (validation par bloc)
